================================================================================

This guide lists every image slot currently on the site, where the files live,
the recommended image dimensions/orientations, suggested clean filenames
(such as entrance_mandap.jpg / archway_entrance.jpg), and the content files
to update.

--------------------------------------------------------------------------------
1. RECOMMENDED IMAGE SPECIFICATIONS & BEST PRACTICES
--------------------------------------------------------------------------------
• Format: JPG, WebP, or PNG (Sharp optimizes to WebP/AVIF at build time).
• Resolution:
  - Hero / Full bleed headers: 1920 × 1080 px or 2400 × 1350 px (16:9 Landscape)
  - Gallery & Project Photos: 1600 × 1067 px (3:2 Landscape) or 1200 × 1500 px (4:5 Portrait)
  - Detail / Portrait shots: 1200 × 1600 px (3:4 or 4:5 Portrait)
  - Service Cards: 1200 × 800 px (3:2 Landscape)
• File Naming Convention:
  - Use lowercase letters, hyphens, or underscores (e.g. entrance_mandap.jpg or entrance-mandap.jpg).
  - Avoid special characters (#, %, &, ?, spaces) in image filenames.
• Directory Location:
  - All images live inside: `src/assets/media/`
  - Subfolders: `hero/`, `about/`, `home/`, `services/`, `gallery/`

3. HOW TO REPLACE IMAGES (TWO EASY METHODS)
================================================================================

METHOD A: DIRECT FILE SWAP (RECOMMENDED FOR BULK REPLACEMENT)
1. Name your photos with your chosen names (e.g., entrance_mandap.jpg, archway_entrance.jpg).
2. Move them into the respective folder in:
   `src/assets/media/hero/`
   `src/assets/media/about/`
   `src/assets/media/home/`
   `src/assets/media/services/`
   `src/assets/media/gallery/`
3. Update the path in the matching `.md` or `.yaml` file.
   Example in `src/content/pages/home.yaml`:
     image: /src/assets/media/hero/entrance_mandap.jpg
     imageAlt: "Bespoke gold and ivory floral mandap entrance with soft lighting"
4. Run `npm run check` or `npm run dev` to verify the build.

METHOD B: VIA PAGES CMS (NO CODE REQUIRED)
1. Open Pages CMS (`app.pagescms.org`).
2. Go to Media → upload your new photos.
3. Edit the desired Page, Service, or Project.
4. Select the newly uploaded photo and update the Alt text.
5. Hit Save. Changes automatically trigger a build & deploy!
